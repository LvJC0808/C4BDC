- **deterministic_top_k**：score 量化到 1e-4 + stock_id 字典序 tie-break，吸收浮点尾差

## 6. 关键实证：AVX-512 不是必要条件，历史漂移已被同机复现推翻

**两个无 AVX-512 节点 + 同机时间序列对比，三重推翻历史假说**：

| 节点 | CPU | AVX-512 | 场景 A | 场景 B | 结论 |
|---|---|---|---|---|---|
| Linux 4060 队友 | i7-13700H | ❌ | ✅ | ✅ | 工程链跨节点有效 |
| WSL Ubuntu（主开发者）| **i9-13900HX** | ❌ | ✅ | ✅ | 同机曾漂移 `5e8b8b0f...`，今日复现 golden |

**关键发现**：
- **i9-13900HX 曾在 2026-04 上旬观测漂移 `5e8b8b0f...`，今日同机同 CPU 产出 golden `f13034946...`** → 直接证明当年漂移来自**包版本/LF 等已修复工程问题**（commits `2599904` + `42abc7f`），**不是 CPU/SIMD 路径**
- "AVX-512 假说"基本被推翻
- 已有 **两个"13 代 Intel Mobile 无 AVX-512"节点实证**（i7-13700H + i9-13900HX），与赛方 i7-13650H 同家族 → 赛方复现把握**非常高**

之前在本机 VM 观测到的 `5e8b8b0f...` 漂移，**最可能源于早期未锁版的包差异 / 行尾未强制 LF**，而非 SIMD 路径。详见 `../canonical/04-reproducibility.md` §4.1。
